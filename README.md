# Learning Playwright 🎭

A hands-on JavaScript learning journey — from the absolute basics through operators, data types, and engine internals — built as a foundation for mastering Playwright test automation.

## Structure

| Module | Topics |
|--------|--------|
| **01_Basics** | Hello World, `console.log` |
| **02_JavaScript_Concepts** | `let`, `var`, `const` — scope, hoisting, TDZ |
| **03_Identifier** | Naming rules, conventions (camelCase, PascalCase, snake_case), comments, interview questions |
| **04_Literals** | String/numeric/boolean/null/undefined literals, number systems (binary, octal, hex), BigInt, `Infinity`, `NaN`, numeric separators |
| **05_Operators** | Data types, assignment, arithmetic, comparison (`==` vs `===`), logical operators, confusing comparisons & gotchas |
| **IQ_Notes** | Deep-dive Markdown on V8 internals (Ignition + TurboFan), `let` vs `var` vs `const` breakdown |

## Progression

Files are numbered sequentially (`01`, `02`, … `19`), building concepts step-by-step. Each file is self-contained and runnable with Node.js:

```bash
node "05_Operators/19_Confusing_Comparison2.js"
```

Every concept is demonstrated with executable `console.log` examples alongside short, colloquial explanations — no fluff, just code that runs.

## Why This Exists

This repo tracks my JavaScript fundamentals study, structured so each concept is isolated, runnable, and easy to revisit. The numbered modules mirror a logical learning path: start with basics, hit the tricky parts (type coercion, comparisons, TDZ), then reinforce with interview-style questions and engine internals.
